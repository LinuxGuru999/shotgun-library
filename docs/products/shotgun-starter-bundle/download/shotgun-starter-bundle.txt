# Renewal Tracker Template

Never miss a subscription renewal again

## Overview
A copy-ready template.

## Template

```markdown
# [Title]

Date: [YYYY-MM-DD]
Owner: [name]

## Context
[Why this exists]

## Key points
- [point 1]
- [point 2]

## Decisions
| Decision | Owner | Date |
| --- | --- | --- |

## Next actions
- [ ] [action] — [owner] — [due]

## Notes
[Anything worth keeping]
```

## Tips
- Keep sections short.
- Review weekly and archive what is no longer relevant.
