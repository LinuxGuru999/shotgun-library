Overview

Newsletter Issue Planner is a reusable template for creators who want to map one newsletter issue from idea to send in a single working session. It combines an issue skeleton, a subject line bank, and a send checklist so you can draft, refine, and publish without switching tools. It is a planning aid, not a writing service or automation.

Use cases

  • A solo creator drafting a weekly issue in one focused sitting without losing the thread
  • A creator batching four issue outlines for the next month before writing full copy
  • An editor or VA checking links, formatting, and CTA placement before the issue is sent

How to use it

  1. Download the file and open it in your preferred notes or document app
  2. Fill the issue skeleton with your topic, sections, and call to action
  3. Choose a subject line from the bank, complete the send checklist, then publish
