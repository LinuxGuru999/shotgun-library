Overview

The Privacy Toolkit is an app bundle of heavy-duty, offline-first developer utilities designed for engineers who handle sensitive data. It helps you process, inspect, and convert data locally on your machine without risking leaks to third-party servers.

Use cases

  • Quickly parsing and formatting production JWTs or JSON payloads containing PII without pasting them into sketchy online web tools.
  • Generating cryptographically secure secrets, UUIDs, and hashes locally behind a corporate firewall with zero internet access.
  • Scrubbing metadata from configuration files and debugging logs before sharing code snippets in public GitHub issues.

How to use it

  1. Download the compressed app bundle directly to your local machine.
  2. Extract the binaries and move them to your local applications or bin directory.
  3. Launch the utilities immediately with zero configuration, sign-ups, or network calls.
