Overview

MovoaTools-Integration-Kit is a ready-to-use script that connects Movoa's text-to-video and photo-to-video capabilities, including sound handling, into the Agno framework. It is built for developers and creators who want to automate AI video generation workflows without wiring every API call by hand. Because output limits and costs depend on your Movoa account and plan, it does not provide truly unlimited generation on its own.

Use cases

  • Automating short marketing clips from product photos and prompts in an Agno agent workflow
  • Batch-generating social media videos with synchronized audio from text descriptions
  • Prototyping AI video features in a local Agno app before integrating them into a larger product

How to use it

  1. Download the kit and place the script files in your Agno project directory
  2. Add your Movoa API credentials and configure the toolkit settings in the provided config file
  3. Run the example agent script to generate your first text-to-video or photo-to-video clip with sound
