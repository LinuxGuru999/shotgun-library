Overview

Log Cleaner Script is a small command-line utility for developers that filters noisy log output by configurable patterns and normalizes timestamps so important events stand out. It accepts either a file path or piped stream, making it easy to clean logs during debugging, CI output review, or incident triage.

Use cases

  • Triage a production error log by removing health-check and heartbeat lines while preserving stack traces and request IDs.
  • Normalize mixed timestamp formats in CI test output before comparing runs across environments.
  • Pipe a live application stream through the script to reduce alert noise while retaining warnings and errors.

How to use it

  1. Download and extract the script, then place it on your PATH or in your project scripts folder.
  2. Run it with a file path or pipe log data into stdin, choosing filters and timestamp format.
  3. Review the cleaned output and adjust pattern filters until only useful lines remain.
